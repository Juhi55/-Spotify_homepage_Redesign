1. Why this approach?

I chose to redesign Spotify's homepage around music discovery rather than simply reproducing the existing Spotify interface. My goal was to create a strong first impression within the first few seconds while showing the product instead of relying only on marketing copy.

I used React with Vite, CSS, Framer Motion, and Lucide React. React made it easy to separate the page into reusable components, while Framer Motion was used for subtle entrance animations. I also added an interactive demo music player in the hero so the main product experience is immediately visible.

I deliberately avoided adding unnecessary pages, authentication, a backend, or a real Spotify API because the assignment focuses on a polished homepage rather than a complete music-streaming application.

2. Trade-off

The main trade-off was choosing depth and polish over functionality. Under the time limit, I focused on the visual hierarchy, responsive design, product showcase, and a meaningful music-player interaction instead of implementing real music streaming or a complete Spotify clone.

With a full week, I would improve accessibility testing, add more detailed player interactions, test the design across more devices and browsers, and explore connecting the interface to an appropriate real music-data source.

3. AI usage

I used AI tools during development for implementation assistance, debugging, component structure, CSS suggestions, and troubleshooting errors.

I personally reviewed, tested, and modified the generated code rather than submitting it without understanding it. I verified the main interactions, responsive behavior, animations, navigation, and production build. I also made the final design and implementation decisions based on the assignment requirements.

4. Design principles

- No fabricated testimonials, user counts, or company logos.
- Demo music and artist names are clearly presented as concept/demo content.
- Animations are intentionally limited and used to support the experience rather than decorate every section.
- The layout was designed to work at both 390px mobile width and 1440px desktop width.
- The project is an unofficial Spotify redesign concept, not an official Spotify product.
